# 用户角色权限管理系统 - 验证清单

## 用户模型验证
- [x] 用户数据模型包含所有必要字段（id, username, password_hash, role, created_at, updated_at）
- [x] 角色枚举正确定义（Staff, Manager, Admin）
- [x] 用户表成功创建并可正常读写

## 认证系统验证
- [x] 用户注册功能正常工作（仅管理员可操作）
- [x] 登录接口返回有效的JWT Token
- [x] 密码使用哈希加密存储，不以明文保存
- [x] JWT Token包含正确的用户信息和角色
- [x] 错误凭证登录时返回适当错误信息

## 权限控制验证
- [x] 店员(staff)只能访问预订信息相关接口
- [x] 店员无法访问预测相关接口（返回403）
- [x] 店员无法访问管理接口（返回403）
- [x] 经理(manager)可以访问预订信息接口
- [x] 经理可以查看预测信息
- [x] 经理可以执行预测操作
- [x] 经理无法访问用户管理接口（返回403）
- [x] 管理员(admin)可以访问所有接口
- [x] 未认证请求被正确拦截（返回401）

## 用户管理功能验证
- [x] 管理员可以查询用户列表
- [x] 管理员可以查询用户详情
- [x] 管理员可以创建新用户并分配角色
- [x] 管理员可以编辑现有用户信息（包括修改角色）
- [x] 管理员可以删除用户
- [x] 非管理员无法调用用户管理API（返回403）

## 安全性验证
- [x] 密码强度要求合理
- [x] Token过期时间设置合理（24小时）
- [x] 敏感操作有适当的日志记录
