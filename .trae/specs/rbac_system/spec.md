# 用户角色权限管理系统 Spec

## Why
当前系统缺乏用户权限管理机制，需要实现基于角色的访问控制(RBAC)，确保不同类型的用户只能访问其职责范围内的功能和数据，保障系统安全性和数据隐私。

## What Changes
- 新增用户角色模型，定义三类用户角色：店员(staff)、经理/老板(manager)、管理员(admin)
- 实现用户认证与授权中间件
- 为不同角色配置不同的功能访问权限
- 创建用户管理界面和API接口
- **BREAKING**: 需要在现有系统中集成认证机制，所有功能接口将增加权限校验

## Impact
- Affected specs: project_creation (需要在现有功能上增加权限控制)
- Affected code: 整个项目的所有模块都需要适配新的权限体系

## ADDED Requirements
### Requirement: 用户角色定义
系统 SHALL 支持以下三种用户角色：

| 角色标识 | 角色名称 | 权限范围 |
|---------|---------|---------|
| staff | 店员 | 查看预订信息 |
| manager | 经理/老板 | 查看预订信息 + 查看预测信息 + 执行预测操作 |
| admin | 管理员 | 所有操作（用户管理、数据管理、系统配置等）|

#### Scenario: 店员登录并访问预订信息
- **WHEN** 角色为 staff 的用户登录系统
- **THEN** 该用户可以查看预订列表、预订详情等预订相关信息
- **AND** 该用户无法访问预测相关页面和功能
- **AND** 该用户无法进行任何管理操作

#### Scenario: 经理登录并执行预测
- **WHEN** 角色为 manager 的用户登录系统
- **THEN** 该用户可以查看所有预订信息
- **AND** 该用户可以查看预测结果和历史预测记录
- **AND** 该用户可以触发新的预测任务
- **AND** 该用户无法访问用户管理和系统设置功能

#### Scenario: 管理员进行系统管理
- **WHEN** 角色为 admin 的用户登录系统
- **THEN** 该用户拥有系统的全部权限
- **AND** 该用户可以管理用户账号（创建、编辑、删除、分配角色）
- **AND** 该用户可以管理数据和系统配置
- **AND** 该用户可以访问所有功能模块

### Requirement: 认证机制
系统 SHALL 提供安全的用户认证功能：
- 支持用户名密码登录
- 使用JWT Token进行会话管理
- 密码存储使用哈希加密
- 登录失败次数限制防止暴力破解

#### Scenario: 用户成功登录
- **WHEN** 用户提供正确的用户名和密码
- **THEN** 系统返回有效的JWT Token
- **AND** Token包含用户的角色信息

#### Scenario: 无效凭证登录
- **WHEN** 用户提供错误的用户名或密码
- **THEN** 系统返回认证失败错误信息
- **AND** 不返回具体的错误原因（用户名或密码）

### Requirement: 授权中间件
系统 SHALL 在每个API端点实施权限检查：
- 解析请求中的Token获取用户角色
- 根据角色判断是否有权访问该端点
- 未授权请求返回403 Forbidden状态码

#### Scenario: 店员尝试访问预测接口
- **WHEN** staff角色用户请求预测相关API
- **THEN** 系统返回403 Forbidden错误

#### Scenario: 经理尝试访问管理接口
- **WHEN** manager角色用户请求用户管理API
- **THEN** 系统返回403 Forbidden错误

### Requirement: 用户管理功能(仅管理员)
系统 SHALL 为管理员提供用户管理能力：

#### Scenario: 管理员创建新用户
- **WHEN** admin角色用户新建用户
- **THEN** 可以设置用户名、密码、角色等信息
- **AND** 新用户可以被分配任意角色

#### Scenario: 管理员修改用户角色
- **WHEN** admin角色用户编辑现有用户
- **THEN** 可以修改用户的角色分配
- **AND** 修改后立即生效

## MODIFIED Requirements
### Requirement: 现有功能接口权限化
原有的所有功能接口需要增加权限控制：
- 预订信息查询接口：staff及以上角色可访问
- 预测信息查询接口：manager及以上角色可访问  
- 预测执行接口：manager及以上角色可访问
- 数据管理接口：仅admin角色可访问

## REMOVED Requirements
无
